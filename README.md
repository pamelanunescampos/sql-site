# 🗄️ SQLá,bora!

Projeto em grupo desenvolvido para a disciplina de Banco de Dados.

## 📖 Sobre o projeto

O blog mostra como organizar tabelas para evitar repetição de dados, reduzir erros e facilitar a manutenção. O conteúdo é apresentado em formato de artigo e cobre:

- O que é normalização e por que ela importa
- **1FN (Primeira Forma Normal):** campos atômicos, um valor por célula
- **2FN (Segunda Forma Normal):** sem dependências parciais da chave primária
- **3FN (Terceira Forma Normal):** sem dependências entre atributos não chave
- Tabelas de exemplo com destaque visual: amarelo para o problema e verde para a versão corrigida
- Seção da equipe com links para GitHub, Instagram e LinkedIn de cada integrante

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis CSS, Grid, Flexbox e layout responsivo)
- Google Fonts: Syne e DM Sans

Não há dependências nem etapa de build.

## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
   ```

2. Entre na pasta:

   ```bash
   cd NOME-DO-REPOSITORIO
   ```

3. Abra o arquivo `index.html` no navegador (duplo clique ou arraste para a janela).

> As fontes são carregadas pela internet. Sem conexão, o navegador usa as fontes padrão do sistema.

## 🎨 Personalização

Cores, fontes e tamanhos ficam nas variáveis no topo do `style.css`, no bloco `:root`. Para mudar o visual do blog, basta editar esses valores.
